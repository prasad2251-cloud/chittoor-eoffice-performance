GitHub Pages:
1. Upload all files into the same repository root.
2. Keep the filenames exactly as shown.
3. Settings -> Pages -> Deploy from branch -> main -> /(root).
4. Open the GitHub Pages URL.
5. If the old page remains, press Ctrl+F5.

To update E-Office data later:
- Replace only eoffice_data.json.
- Do not change the JSON field names.
- The dashboard will automatically read the new data.

The dashboard is styled to follow the supplied Chittoor Police Smart Policing dashboard:
- compact circular logo/officer images
- blue header
- pill navigation
- KPI cards
- Top 5 / Bottom 5
- composite score chart
- performance/trends/category/report sections
- complete E-Office data table

The data remains E-Office data only.
